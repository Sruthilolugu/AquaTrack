# AquaTrack
#Groundwater is a vital resource for drinking water, agriculture, and industry, but its availability is increasingly threatened by over-extraction and climate variability. This project aims to forecast groundwater levels for the years 2025–2026 using historical groundwater monitoring data published by the Central Ground Water Board (CGWB).

#The dataset contains pre-monsoon Depth to Water Level (DTWL) measurements from 2014 to 2024, along with location details such as state, district, village, latitude, and longitude. After data cleaning and preprocessing, historical groundwater trends are analyzed for each observation location.

#Time series and machine learning models are trained on past data to predict future groundwater levels. The forecasted results are visualized to identify regions at risk of groundwater depletion. This project supports data-driven groundwater management and provides actionable insights for policymakers, researchers, and local authorities.
